# PathSnap first-evaluation visualizations

These presentation assets were generated from the existing student-test data, the existing saved model, and the
existing `results/models/model_comparison.csv`. No estimator was fitted, no cross-validation was rerun, no Bayesian
optimization was run, and no model artifact or comparison CSV was overwritten.

## What to tell the TA

1. **Matched-route map:** This is student-test trip `00000000`. Blue shows the observed GPS trajectory, gray shows
   nearby road-network geometry, and red shows the saved HistGradientBoosting model followed by the existing Viterbi
   inference path. The map is inference-only and contains no reference route layer.
2. **Speed distribution:** Speeds are calculated from consecutive GPS points using the local metric projection and
   timestamp differences. Non-positive time intervals are excluded. The plot uses all 10 student-test trips.
3. **GPS-to-road distances:** Each bar is an exact point-to-segment distance for generated candidates within the
   documented 50 m radius, using up to 8 candidates per observation. It shows how close plausible road segments are to
   the observed GPS points; it is not a fabricated error metric.
4. **Five-model comparison:** The bars are read directly from the existing comparison CSV. CV Macro F1 and student
   Top-1 accuracy are displayed exactly as stored; this plot does not recompute or alter those results.
5. **Confusion matrix:** This is candidate-level binary inference from the saved HistGradientBoosting artifact over
   all generated student-test candidates. The positive class is the nearest supplied-route arc used as a heuristic
   label. It is therefore a diagnostic of candidate classification, not proof of independently verified physical
   ground truth. Counts are TN 16,385, FP 78,202, FN 3,052, TP 16,052.

## Reproduce without training

```powershell
python -m pathsnap.visualization.first_evaluation_plots `
  --data-root "Student folder/Student folder" `
  --model pathsnap/ml_pipeline/artifacts/final_model.joblib `
  --comparison results/models/model_comparison.csv `
  --output-dir results/plots
```

The command performs only data loading, feature generation, model `predict_proba`, and visualization. It does not call
`.fit`, cross-validation, Optuna, or artifact export.
